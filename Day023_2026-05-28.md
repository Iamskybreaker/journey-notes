## 🧠 What I Learned

- **HTTP (HyperText Transfer Protocol):**  
  • The protocol used for communication on the web  
  • Defines how data is transferred between client and server  

- **Request-Response Cycle:**  
  • Client sends a request to a server  
  • Server processes the request  
  • Server sends back a response  

- **Real-World Usage:**  
  • Used in browsing websites  
  • Powers APIs and web applications  
  • Forms the backbone of most internet interactions
