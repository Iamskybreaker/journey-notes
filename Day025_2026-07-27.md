## 🧠 What I Learned

- **Ping:**  
  • A networking command used to test connectivity between devices  
  • Helps determine whether a destination is reachable across a network  
  • Uses responses to provide information about connection status  

- **Ping Responses:**  
  • Request timed out → No response received within the expected time  
  • Destination unreachable → The network path to the destination could not be completed  
  • Successful replies indicate communication is possible  

- **DNS & Ping:**  
  • Ping can also help check whether DNS name resolution is working correctly  
  • A successful resolution allows a domain name to be translated into an IP address  

- **Traceroute:**  
  • A tool used to track the path packets take from source to destination  
  • Helps identify points where delays or failures occur during communication
