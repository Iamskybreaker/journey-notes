## 🧠 What I Learned

- **Ports:**  
  • Logical communication endpoints used by services and applications  
  • Help devices determine which specific service should receive incoming data  

- **IP Address vs Port:**  
  • IP address identifies the device on a network  
  • Port identifies the specific application or service running on that device  

- **Port Numbers:**  
  • Different ranges exist for different purposes  
  • Includes well-known, registered, and dynamic/private ports  

- **Common Port Examples:**  
  • HTTP  
  • HTTPS  
  • FTP  
  • SMTP
